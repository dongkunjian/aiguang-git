# 多智能体协同规则模板包

这是一套**可整体拷贝**的多智能体协作脚手架。拷到任何新项目根目录，填完占位符就能用。

---

## 怎么用（新项目三步）

1. **拷**：把本文件夹整体复制到新项目根目录
2. **填**：
   - 打开《多智能体协作章程（空白模板）.md》，把所有 `<...>` 占位符填成你们团队实际情况
   - 打开《📞联络台.md》，填头部（项目名 / 主目标 / 交付物 / 截止）
3. **拉人**：按章程「附录 B」逐个拉智能体入队——入队的人会自己在「智能体们/」下建文件夹

---

## 目录结构

```
多智能体协同规则/
├── README.md                    ← 本文件
├── 多智能体协作章程（空白模板）.md  ← 规则总纲（铁律 / 角色 / 流程 / 状态 / 异常）
├── 📞联络台.md                  ← 项目唯一信息源
├── _模板/
│   ├── 任务卡模板.md             ← 派单时复制改名，丢进对方投递箱
│   └── 工作记录模板.md           ← 每个智能体入队时复制到自己文件夹
└── 智能体们/                    ← 每个智能体一个代号文件夹
    └── <代号>/
        ├── 📥投递箱/            ← 别人投任务到这里
        ├── 📂工作区/            ← 自己干活的中间产物
        └── 📝工作记录.md         ← 自己的流水账
```

---

## 核心动作链（一句话记）

> **开工先读联络台 → 从自己投递箱取卡 → 工作区干活 → 当场写工作记录 → 要接力就丢进下家投递箱 → 最后在联络台贴交接单**

---

## 文件说明

| 文件 | 作用 | 谁来改 |
| --- | --- | --- |
| 章程（空白模板） | 定义铁律、角色、流程、状态词、异常处理 | 立项时填一次，后续改需甲方同意 |
| 📞联络台 | 项目唯一进度源 | 全员读写，进度只在这里更新 |
| _模板/任务卡 | 派单用 | 派单人复制使用 |
| _模板/工作记录 | 个人流水账模板 | 智能体入队时复制 |

---

## 状态词（统一用，不自己造）

`待办` → `进行` → `待验收` → `已交付`（或 `退回` 回炉）；卡住用 `挂起`。
